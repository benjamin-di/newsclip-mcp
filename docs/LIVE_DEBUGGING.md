# Private live diagnostics

Investigate a live provider failure privately. Record the version, provider,
closed error category and whether the operation used an existing session or a
fresh human connection. A sign-in pass does not establish article entitlement.

Do not upload raw pages, browser traces, cookies, profiles, screenshots, article
bodies, account details or internal network configuration. Reproduce code
defects with invented fixtures before submitting a public report. Preserve the
first failure; repeating sign-ins or clearing state can destroy useful evidence
and trigger publisher restrictions. A provider refusal is not evidence that its
selectors or the shared browser runtime need to change.
